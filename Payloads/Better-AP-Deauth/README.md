This payload is intended to be placed within the /recon/access_points directory. 
It will knock all associated clients off of a targeted Access Point, which is intended to be found through the RECON GUI.
This payload's use case is for a targeted AP deauth that is rapidly deployed through the convenience of the RECON GUI.

**This payload will run until terminated by the operator, which can be done by pressing the "A" button (the green button) on the pager.**
